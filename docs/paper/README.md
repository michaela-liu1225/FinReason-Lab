# Report availability

The submitted report for **FinReason-Lab** is not redistributed in this personal portfolio mirror because the original PDF contains the institutional email addresses of all six team members.

The report is a team-authored UCL COMP0087 submission by Yike Zhang, Jiaming Wei, Yuhao Wang, Yuxin Liu, Jiaqi Wang, and Victor Lang. This omission does not change the attribution or provenance of the work.

For the canonical project history, see the [upstream team repository](https://github.com/Quarkgluonmixture/FinQA). For executable reproduction details and the limits of the packaged artifacts, see [`../repro/README.md`](../repro/README.md).
